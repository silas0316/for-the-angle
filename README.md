# For the Angle

A camera-angle reference tool for writing image and video prompts.

Orbit a camera around a wireframe subject — cube, sphere, phone, laptop, figure,
car or room — and it writes a plain-English sentence describing that exact angle,
ready to paste into a prompt.

- Place the camera by dragging its X / Y / Z tracks, or drag to orbit in 15° steps
- Lock any axis to hold it while you adjust the others
- Lens choice (18–200mm) affects both the preview and the wording
- Live camera preview beside the rig, so you see the shot you're describing

Single self-contained HTML file, no build step and no dependencies.
